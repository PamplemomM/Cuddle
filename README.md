# **Cuddle**

## **Description**

![Panda](https://img.shields.io/badge/Recreation%20of%20the%20PandaLibrary-purple)


Cuddle is the recreation of the popular Pandas Library.


## **Usage**
  
To Compile the Library, type in a bash terminal :
```bash
make re
```
Include your lib using `-L -lcuddle` with your compilation command.

Example usage:

```bash
gcc -o my_first_program main.c -L -lcuddle
```
